# Purpose

To prevent **code rot**. It means that every new feature you add breaks two old features and your codebase are too scary to touch.

# Why they matter ?

They guide to toward **loose coupling** (classes don't depend on inner guts of other classes) and **high cohesion** (each class has a single, clear job). This makes your code flexible to change and easy to fix.

# Hierarchy

They build on each other. The first two (SRP, OCP) are about class design. The next two (LSP, ISP) are about class relationship, And last one (DIP) is about class dependency.
