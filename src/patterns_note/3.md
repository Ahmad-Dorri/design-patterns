# Pattern number three

Favor composition over inheritance.

> details in the duck application:

In the duck application, we use inheritance. We created a base class called duck and all other subclasses should extend this class. But something that is vary like fly behavior or quack behavior is created in different classes. We can create another example for this. If we have a base car class, we know that each car has tires. But we can create another interface for shape of the tire. Then we create different shape of that tire using implementing that interface. Now we can use composition for the shape of tire, and create and change shape of tire in runtime.
