# Purpose

These are the design tools for every OOP application. By using these tools we can take a chaotic, real-world problem and break it into discrete, self-contained objects (like lego bricks) that talk to each other.

# Why they matter ?

They allow us to write maintainable (easy to fix), reusable (don't repeat yourself) and extensible (easy to add feature without breaking the old one) code.

# Hierarchy

Abstraction and encapsulation are about safety and design (hiding complexity). Inheritance and polymorphism are about relationship and behavior (connection objects together).
