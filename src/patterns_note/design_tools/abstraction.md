# Definition

Hiding complex implementation details and showing only the essential features of an object.

> For example in a remote control we only see some buttons that we can navigate and work with it, but if we open it, we can see some electric boards, wires and etc. The remote control hide that details and only show feature that is necessary for users. We can achieve this by using abstract classes, interfaces and clean public method names.

### Suggestion

We should not over abstract or not abstract things. We should abstract when needed and hide complex details that don't not matter for users.
